# 예시: 가상 인물의 공고 분석

> 이 문서의 인물, 공고, 금액은 모두 **설명을 위해 만든 가상의 값**입니다. 실제 공고나 실제 사람과 관계없습니다.
> 플러그인이 어떤 순서로 판단하고, 결과를 어떤 모양으로 보여 주는지 확인하는 용도입니다.

## 가상 프로필

| 항목 | 값 |
|---|---|
| 출생연도, 혼인 | 1999년생, 미혼 |
| 세대 | 1인 세대, 세대주, 무주택 |
| 거주 | 서울 3년 이상 연속 거주 |
| 직장 | 서울 도심권 |
| 전년도 총급여 (원천징수영수증) | 3,600만 원, 12개월 근무 → 월 300만 원 |
| 최신 건강보험 보수월액 | 월 330만 원 |
| 총자산 | 6,000만 원 (현재 보증금 포함), 차량 없음 |
| 현재 집 | 전용 20㎡ 원룸, 보증금 5,000만 원, 월세 55만 원, 관리비 8만 원 |

## 가상 공고

"○○역 청년안심주택 입주자 모집" (예시)

- 청년 특별공급: 본인 소득 월 400만 원 이하, 총자산 2억 5,000만 원 이하. 소득 순위와 지역 순위로 선정
- 일반공급: 소득과 자산 제한 없음, 추첨
- 일반근로자 소득 증빙: **전년도 근로소득원천징수영수증**
- 공급 주택: 25형(전용 21㎡) 특별 40호와 일반 160호, 35형(전용 30㎡) 특별 3호와 일반 12호

## 1. 자격 판정 (`housing-eligibility`)

| 공급유형 | 공고 기준 | 사용자 값 (자료와 시점) | 판정 |
|---|---|---|---|
| 청년 특별공급 | 본인 소득 월 400만 원 이하 | 월 300만 원 (전년도 원천징수영수증) | 충족 |
| 청년 특별공급 | 총자산 2억 5,000만 원 이하 | 6,000만 원 | 충족 |
| 일반공급 | 제한 없음 | - | 신청 가능 |

이 공고는 서류 제출형이라 **전년도 원천징수영수증**으로 심사합니다. 올해 오른 보수월액(330만 원)은 반영되지 않습니다. 같은 사람이라도 건강보험 보수월액을 조회하는 공고라면 결과가 달라질 수 있습니다.

## 2. 당첨 구조 (`housing-unit-pick`)

- 35형은 특별공급이 **3호뿐**이고, 선정 순서가 소득 순위 → 지역 순위입니다. 이 인물은 서울 거주라 지역 순위는 유리하지만, 소득이 더 낮은 신청자가 먼저 뽑힙니다.
- 25형은 특별공급 40호로 물량이 많지만, 전용 21㎡로 현재 집과 거의 같은 크기입니다.
- 접수 전이라 경쟁률은 알 수 없으므로, "당첨 확률이 몇 배"처럼 숫자로 말하지 않습니다.

## 3. 실질 월 주거비

| 후보 | 보증금 | 월세 | 관리비(가정) | 추가 보증금 비용 (연 4%) | 합계 |
|---|---:|---:|---:|---:|---:|
| 현재 집 | 5,000만 | 55만 | 8만 | - | **63만** |
| 35형 특별 (보증금 최대) | 1억 2,000만 | 45만 | 9만 | 23.3만 | **77.3만** |
| 35형 일반 (보증금 최대) | 1억 4,000만 | 54만 | 9만 | 30만 | **93만** |

관리비는 공고에 금액이 없어 "가정"으로 표시했습니다.

## 4. 추천

가중치는 출퇴근 30%, 가격 30%, 당첨 가능성 20%, 면적 15%, 건물 5%를 썼습니다.

**결론: 35형 특별공급에 지원하되, 이사는 비용 증가를 감수할 때만 하세요.**

- 좋아지는 점: 전용면적 20㎡ → 30㎡, 신축
- 나빠지는 점: 월 주거비 약 14만 원 증가, 보증금 7,000만 원 추가 필요
- 일반공급 35형은 월 30만 원 가까이 늘어나 추천하지 않습니다.
- 결론이 바뀌는 조건: 추가 보증금을 연 2%대로 마련할 수 있다면 비용 차이가 크게 줄어듭니다.

## 5. 신청 준비 (`housing-apply`)

캘린더에는 공고당 두 개만 등록합니다.

1. 청약 접수 첫날 (메모: 신청 유형, 순위, 자격 판정 요약, 마감 일시)
2. 서류 대상자 발표일 (발표 시각에 알림)

등록하고 나면 `housing-tracker`가 신청 현황에 "신청예정"으로 기록합니다.
