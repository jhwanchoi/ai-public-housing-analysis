# 자격과 순위 판정

개인 데이터 위치는 `housing-notice-analysis`의 공통 규칙을 따른다.

## 원칙

- **자격 판정이 가장 먼저다.** 모든 신청 경로가 막히면 사유와 공고 근거(쪽수, 문구)만 쓰고 끝낸다. 비용, 면적, 출퇴근은 분석하지 않는다.
- **공급유형별로 따로 판정한다.** 같은 공고 안에서도 청년 특별공급(본인 기준)과 일반공급(3인 이하 기준)의 소득 상한이 다를 수 있다.
- 공고마다 새로 계산한다. 다른 공고에서 나온 순위를 가져오지 않는다.
- 모르는 개인정보는 짐작하지 않는다. 판정에 꼭 필요한 것만 짧게 묻는다.

## 확인 순서

1. 기준일(공고일)과 그날 기준 만 나이
2. 혼인 여부, 무주택(본인 또는 세대), 세대 구성, 세대주 여부
3. 거주지 요건과 지역 우선(연속 거주 기간)
4. **소득**: 상한 금액, 산정 자료, 산정 시점 → `references/income-rules.md`
5. 자산(임차보증금 포함 여부)과 자동차가액
6. 부모 소득과 자산 포함 여부, 부모 검증 범위(이혼, 사망, 세대 분리)
7. 청약통장 요건, 가점 항목, 과거 당첨 이력과 재당첨 제한, 부적격 이력

## 판정 규칙

- 경계선에 있으면 "가능"이라고 단정하지 않는다. "○○ 자료가 반영되면 기준을 넘음(또는 충족)"처럼 조건을 붙이고 확인 방법을 함께 쓴다.
- 소득 기준을 넘어도 **후순위로 신청할 수 있는 공고**가 있다(예: SH 장기미임대 2순위). 초과했다고 곧바로 부적격으로 결론 내지 않는다.
- 산정 자료나 시점이 공고에 없으면 기관 문의 문구를 만든다. 개인 소득은 말하지 않고 기준만 묻는 짧은 문장으로 만든다.
  > "○○ 공고 소득 기준을 문의드립니다. 전년도 연간 소득을 보나요, 건강보험 보수월액을 보나요? 보수월액이라면 몇 월분을 적용하나요?"
- 사용자가 새 소득 금액을 알려주면 어떤 자료의 금액인지부터 확인한다. 필요하면 조회 경로를 안내한다.
  - 원천징수영수증: 홈택스 → 나의 소득·연말정산 → 지급명세서 등 조회 → 귀속연도 선택 → 근로소득 지급명세서 **보기**. 간이지급명세서와 구분하고 ㉑총급여와 근무기간을 받는다.
  - 보수월액: 국민건강보험공단 보험료 조회 화면의 **보수월액 열**(보험료 금액이 아님).
