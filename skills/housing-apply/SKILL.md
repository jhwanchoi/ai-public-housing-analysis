# 신청 실행

개인 데이터 위치는 `housing-notice-analysis`의 공통 규칙을 따른다.

## 캘린더 등록 (공고당 2개만)

사용자가 요청했거나 지원을 결정했을 때만 등록한다. 등록 전에 같은 공고의 기존 일정을 검색해 중복을 피한다.

1. **청약 접수 첫날**
   - 시작 시각부터 그날 마감 시각까지. 여러 날 접수여도 첫날만 등록한다.
   - 제목에 공고명, 신청 단위, 최종 마감 시각을 넣는다.
   - 알림: 하루 전, 1시간 전.
2. **그 신청에 대한 서류심사 대상자 발표**, 발표 시각에 맞춰
   - 서류대상 발표가 따로 없는 공고(당첨 후 서류 제출)는 **당첨자 발표**로 등록하고, 메모에 그 사실을 적는다.
   - 알림: 발표 시각.

접수 첫날 메모에 넣을 것
- 공고명, 공고일, 주택관리번호, 신청 사이트
- 신청 내용: 공급유형 / 순위 / 지역 구분 / 주택군·주택형
- **사용자 자격 판정 요약**: 항목별 기준과 사용자 값
- 신청하면 안 되는 유형과 이유
- 보증금·월세(또는 분양가·토지임대료), 관리비 여부
- 당첨 구조 요약, 당첨 시 주의사항(중복신청 제한, 재당첨제한 등)
- 이후 일정(서류 제출, 계약, 입주)과 문의처

사용자가 "메모를 나한테 줘"라고 하면 캘린더를 다시 고치지 말고 **복사 가능한 텍스트 블록**으로 준다. HTML 태그 없이 대괄호 소제목과 줄바꿈만 쓴다.

등록 후 `housing-tracker`에 신청 예정으로 기록한다.

## 기관 문의 스크립트

- 통화 중이면 **짧게**, 질문 하나씩 쓴다.
- 사용자가 요청하지 않으면 개인 소득 금액을 스크립트에 넣지 않는다. 기준만 묻는 버전을 먼저 준다.
- 예상 답변별 후속 질문을 1~2개 붙인다.
- 사용자가 통화 결과를 알려주면 출처("○○ 콜센터 안내, 날짜")와 함께 기록하고, 판정을 갱신한다.

주요 문의처: LH 마이홈센터 1600-1004, SH 콜센터 1600-3456, HUG 1566-9009.
