# 새 공고 찾기와 1차 선별

개인 데이터 위치는 `housing-notice-analysis`의 공통 규칙을 따른다.

## 찾아볼 곳

- **SH**: 공고 게시판, 서울주거포털의 공공임대와 공공분양 목록
- **LH**: LH청약플러스의 임대와 분양 공고(서울과 수도권 지역본부)
- **HUG 든든전세**: 공지사항, 모집공고 목록
- **청년안심주택**: 서울시 청년안심주택 모집공고와 단지 홈페이지
- **그 밖에**: 마이홈포털, 청약홈(공공분양, 토지임대부)

사용자가 원하는 지역(예: 서울)이면서 접수 마감 전인 공고만 남긴다. `applications.md`에 이미 있는 공고는 상태만 표시하고 다시 분석하지 않는다.

## 1차 선별 (공고당 간단히)

공고문 전체를 깊게 읽기 전에 **탈락 사유부터** 찾는다.

1. 대상 계층: 청년, 신혼부부, 고령자, 일반 중 사용자가 해당하는지
2. 소득 제한이 있는지, 어떤 **소득표 기준**(본인 1인, 3인 이하, 부모 포함)인지. 사용자의 최신 소득 자료와 비교한다.
3. 자산과 차량 상한
4. 면적과 유형: 사용자가 신청할 수 있는 주택형이 현재 집보다 넓은지
5. 지역 우선, 무주택기간처럼 사용자에게 불리한 선정 방식

판정: `신청 가능`, `조건부`(확인할 항목을 적음), `부적격`(사유 한 줄)

## 출력

| 공고 | 기관 | 접수 기간 | 대상과 주택형 | 소득 기준 | 1차 판정 | 이유 |
|---|---|---|---|---|---|---|

- `신청 가능`과 `조건부`를 위에, `부적격`은 아래에 따로 모은다.
- 마감이 가까운 순서로 정렬한다.
- 끝에 자세히 볼 공고를 1~3개 추천하고, 사용자가 고르면 `housing-notice-analysis`로 넘긴다.
- 출처는 공식 공고 링크로 단다. 요약 사이트에서만 찾은 공고는 그렇다고 표시한다.
