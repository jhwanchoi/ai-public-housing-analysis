# 공고 원문 확보·대조

## 원문 찾기

1. 사용자가 준 링크가 블로그·요약 사이트면 **공식 출처로 거슬러 올라간다.**
   - SH: i-sh.co.kr 공고 게시판, 서울주거포털(housing.seoul.go.kr)
   - LH: apply.lh.or.kr (LH청약플러스)
   - HUG 든든전세: khug.or.kr/jeonse
   - 청년안심주택·공공지원민간임대: 각 단지 공식 홈페이지 + 서울시 청년안심주택 안내
   - 마이홈포털(myhome.go.kr): 보조 확인
2. 공식 사이트가 자동 조회를 막으면 브라우저 도구로 연다. 그래도 안 되면 첨부 파일을 직접 받거나 사용자에게 요청한다.
3. 요약 사이트 정보를 쓸 수밖에 없으면 **"요약 사이트 기준, 공식 원문 미확인"**이라고 밝힌다.

## 반드시 확인할 것

- **정정·변경·취소 공고**: 공급 제외 호수, 임대조건 정정, 일정 변경. 원공고보다 우선한다.
- **문서 내부 모순**: 같은 PDF 안에서 접수 마감·발표일이 다르면 공식 신청 화면 일정을 따르고, 차이를 사용자에게 알린다.
- **(안) 표시 파일**: 실제 게시 여부와 게시일을 확인한다.
- 접수가 이미 끝난 공고는 그 사실을 먼저 알리고, 분석 범위를 사용자에게 맞춘다.

## 파일 읽기

- PDF: `pdftotext -layout`로 텍스트화하고, 표·평면도·위치도처럼 레이아웃이 중요한 쪽은 이미지로 렌더링해서 본다.
- HWPX: zip을 풀어 `Contents/section*.xml`의 텍스트를 추출한다.
- XLSX/XLS: 헤더 행(여러 줄일 수 있음)을 먼저 파악한 뒤 행 단위로 읽는다. 원본 파일은 수정하지 않는다.
- 다운로드한 파일은 별도 작업 폴더에 두고, 스크립트는 그 폴더 밖에서 실행한다.

## 정리 산출물

다음 단계로 넘길 핵심만 정리한다.
- 공고명, 공고일(자격 기준일), 주택관리번호
- 공급유형별 물량과 신청 단위(주택군·주택형·개별 호)
- 소득·자산·차량 조항의 **쪽수**
- 공식 일정: 접수(유형·순위별), 서류대상 발표, 서류 제출, 당첨 발표, 계약, 입주
- 신청 사이트와 문의처
