# 사이트별 원문 확보 방법

공식 사이트는 자주 바뀐다. 아래 방법이 통하지 않으면 공고 페이지를 직접 열어 첨부 링크 구조부터 다시 확인한다.

## 브라우저가 필요한 사이트

| 사이트 | 자동 조회(curl 등) | 이유 |
|---|---|---|
| 서울시 청년안심주택(soco.seoul.go.kr) | 가능 | 첨부 링크(`fileDown.do?atchFileId=...`)가 HTML에 있다 |
| SH(i-sh.co.kr) | 게시판 HTML과 미리보기 이미지는 가능, 원본 첨부는 어려움 | 첨부 다운로드가 JS(`existFile`)로만 동작한다 |
| LH청약플러스(apply.lh.or.kr) | 어려움 | 자동 조회와 파일 직접 다운로드를 막는 경우가 많다. 문서 뷰어로 읽는다 |
| 단지 홈페이지 | 사이트마다 다름 | |

브라우저 도구는 사용자가 **Chrome을 켜고 Claude in Chrome 확장을 연결해 둬야** 쓸 수 있다. 연결 상태는 조사 시작 전에 확인한다(`housing-scout`, `housing-research`의 "브라우저 사전 점검").

## SH (i-sh.co.kr)

1. 공고 목록: `.../brd/m_241/list.do`의 HTML에서 `getDetailView('번호')`로 게시물 번호와 제목을 얻는다.
2. 상세: `.../brd/m_241/view.do?seq=번호`
3. 첨부 미리보기: 상세 HTML 안의 `/main/com/util/htmlConverter.do?brd_id=...&seq=...&data_tp=A&file_seq=N` 링크.
   - 이 링크를 브라우저로 열면 문서 뷰어가 뜨고, 쪽마다 `.../html/<변환ID>.files/1.png, 2.png, ...` 이미지가 붙는다.
   - 변환 ID는 뷰어 페이지의 `img` 주소에서 얻는다. 이미지는 직접 받을 수 있다. 없는 쪽 번호는 PNG가 아니라 HTML이 돌아오므로 파일 형식으로 끝을 판단한다.
4. 쪽 이미지는 텍스트 추출이 안 된다. 목차를 보고 **자격, 소득표, 임대조건, 일정** 쪽만 골라 읽는다.

## LH청약플러스 (apply.lh.or.kr)

1. 공고 목록: `/lhapply/apply/wt/wrtanc/selectWrtancList.do?mi=1026`. 각 공고 링크의 `data-id1~4`가 상세 주소의 `panId`, `ccrCnntSysDsCd`, `uppAisTpCd`, `aisTpCd`다.
2. 상세: `/lhapply/apply/wt/wrtanc/selectWrtancInfo.do?panId=...&ccrCnntSysDsCd=..&uppAisTpCd=..&aisTpCd=..&mi=1026`
   - 상세 페이지 본문에도 단지별 접수, 서류대상자 발표, 당첨자 발표 일정과 정정 사유가 있다. 공고문과 대조한다.
3. 공고문: 첨부 옆 **"바로보기"**(새 창)를 누르면 문서 뷰어가 열린다. 쪽은 이미지로 그려진다.
   - 뷰어 왼쪽 **검색**에 금액이나 낱말을 넣으면 해당 쪽으로 바로 이동한다. 텍스트 레이어가 있어 검색은 된다.
   - 잘 통하는 검색어: 대상 계층의 1인 소득 상한 금액(예: 그해 1인 120% 금액), `임대조건`, `청약접수`, `서류제출대상자`, 자산 상한 금액
   - 위치를 찾은 뒤 화면을 캡처해 표를 읽는다.

## 브라우저 도구 사용 시 알려진 제약

- 페이지에서 실행한 JS 결과에 쿠키나 쿼리스트링으로 보이는 값이 섞이면 출력이 차단된다. 함수 본문 전체 대신 필요한 경로 문자열만 뽑거나, 요소 찾기와 클릭으로 진행한다.
- 브라우저로 다운로드 주소를 열어도 파일이 저장되지 않을 수 있다. 뷰어로 읽는 방법을 먼저 쓴다.
- 쪽 이미지에서 글자를 뽑는 OCR 도구는 기본으로 없다고 가정한다.
